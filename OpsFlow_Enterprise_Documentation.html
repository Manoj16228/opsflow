1. Executive Summary & Problem Statement

1.1 What is OpsFlow?

OpsFlow is a high-performance, enterprise-grade engineering management and Site Reliability Engineering (SRE) orchestration platform designed to unify project delivery, real-time incident war rooms, automated workflows, and compliance auditing in a unified, local-first ecosystem.

Modern technology organizations frequently struggle with fragmented tooling—managing tasks in Jira or Linear, tracking production outages in PagerDuty or Slack channels, running custom automation scripts on cron servers, and paying exorbitant recurring per-seat SaaS subscription fees. OpsFlow solves this by synthesizing full-lifecycle task management, real-time SRE incident triage, zero-trust security, workflow automation, and localized AI intelligence into a single coherent system.

1.2 Core Business & Engineering Value

  • Zero-Cost & Local Sovereignty: Built strictly with open-source runtimes and local storage engines (SQLite / PostgreSQL), eliminating recurring cloud expenditures and preserving absolute data privacy.
  • Sub-Millisecond Real-Time Collaboration: Full duplex WebSocket synchronisation guarantees that updates to tasks, active incidents, and war room triage sessions propagate instantly across all active engineering team members.
  • SRE War Room with Live Triage: A dedicated incident command centre featuring automated severity scoring (SEV-1 Critical through SEV-4 Minor), real-time collaborative chat, event timelines, and post-mortem generation.
  • Enterprise Zero-Trust Security: Granular Role-Based Access Control (RBAC), multi-factor Time-Based One-Time Password (TOTP) authentication, active session governance with remote revocation, and immutable audit logs.
  • Local AI SRE Copilot: An integrated, offline-capable assistant capable of automated root-cause analysis, post-mortem generation, and natural language SQL query translation.
Target Audience: DevOps Engineers, Site Reliability Engineers (SREs), Engineering Directors, System Administrators, and Product Teams requiring enterprise tooling with full privacy and zero ongoing licensing costs.

3.2 Core Data Flow & Lifecycle

  1. Client Interaction: When an engineer takes an action (e.g. creating a task, updating an incident severity, or running an automation), the Next.js client sends an authenticated HTTP request with a Bearer JWT.
  2. Authentication & Tenant Isolation: The Express gateway verifies the token signature, decodes user permissions, and ensures all database queries are strictly scoped to the user's organizationId.
  3. Database Mutation & Audit Trail: Prisma executes an ACID transaction to persist the mutation and simultaneously writes an immutable record to the AuditLog table capturing actor ID, action type, IP address, and metadata.
  4. Event-Driven Automation Trigger: The mutation dispatches an internal domain event (e.g. TASK_STATUS_CHANGED). The Automation Engine matches active workflow rules, checks conditions (e.g., Priority == URGENT), and executes configured actions (auto-assign, escalation notification, webhooks).
  5. WebSocket Broadcast: The Socket.IO server broadcasts a targeted event payload to all room subscribers belonging to that organization, automatically refreshing task boards, notification badges, and war room streams in real time.

3.3 Authentication & Zero-Trust Security Model

OpsFlow enforces enterprise security standards through a multi-tiered security model:

  • Stateless JWT Tokens: Signed with HMAC-SHA256 containing user ID, role, and organization context.
  • RFC 6238 TOTP Two-Factor Authentication: High-security accounts can bind standard authenticator apps (Google Authenticator, Authy, 1Password) using QR code onboarding and encrypted secret keys.
  • Active Session Governance: Every login logs the client user-agent, IP address, and last active timestamp. Users and administrators can terminate suspicious active sessions instantly with one click.

4. Comprehensive Platform Features

4.1 Enterprise Task & Project Orchestration

OpsFlow delivers a responsive, keyboard-driven project tracking system engineered for high-velocity teams:

  • Multi-View Layouts: Seamlessly toggle between visual Kanban Columns (Backlog, Todo, In Progress, Review, Done) and dense, sorting-enabled Data Grids.
  • Power-User Bulk Operations: Select multiple tasks via multi-select checkboxes or click-drag to batch-update status, reassign ownership, change priorities, or export selected items in bulk.
  • Rich Metadata: Task items support priority levels (Low, Medium, High, Urgent), estimation tags, due dates, department allocations, assignee relationships, and subtask dependencies.

4.2 SRE Incident War Room & Live Outage Triage

When production disruptions occur, OpsFlow transforms into a high-stakes Incident Command Center:

  • Severity Classification: Standardized categorization from SEV-1 (Critical Outage) down to SEV-4 (Minor Glitch) with real-time SLA timers.
  • Collaborative War Room Modal: Dedicated incident workspace equipped with live chat, chronological timeline markers, real-time participant badges, and status progression (Investigating → Identified → Monitoring → Resolved).
  • Post-Mortem & Root Cause Analysis: One-click root cause capture, automated resolution metrics (MTTD / MTTR), and incident summaries.

4.3 Event-Driven Workflow Automation Engine

OpsFlow includes a built-in, no-code workflow automation engine allowing engineering managers to automate repetitive processes without writing scripts:

4.4 Local SRE AI Copilot & Assistant

Unlike SaaS tools requiring third-party OpenAI or Anthropic API keys with per-token billing, OpsFlow embeds a 100% free, localized AI Copilot:

  • Instant Root-Cause Analysis: Examines active incidents and suggests systematic diagnostic playbooks (database locks, memory saturation, network timeouts).
  • Natural Language SQL & Query Translation: Translates requests like "Show overdue tasks in DevOps assigned to Sarah" into structured filters.
  • SRE Post-Mortem Drafter: Compiles timeline events and participant notes into structured markdown post-mortem reports.

4.5 OLAP Star-Schema Dimensional Exporter

Data analytics and compliance reporting are native features in OpsFlow. The analytics dashboard provides:

  • Engineering Velocity Metrics: Live tracking of Mean Time to Detect (MTTD), Mean Time to Resolve (MTTR), Task Completion Velocities, and Department Load Distributions.

5. Local Setup & Deployment Guide

5.1 Prerequisites

  • Node.js: v18.0.0 or later (v20+ LTS recommended)
  • Package Manager: npm or pnpm
  • Database: Built-in SQLite (Zero configuration needed) or optional PostgreSQL

5.2 Quickstart Commands

# 1. Clone the repository and navigate to workspace
cd opsflow

# 2. Install backend dependencies and initialize database
cd backend
npm install
npx prisma db push
npx tsx src/database/seeds/seed.ts   # Seeds default enterprise demo data

# 3. Start the Backend API Server (Port 5001)
npm run dev

# 4. In a separate terminal, install and start the Frontend (Port 3000)
cd ../frontend
npm install
npm run dev

6. API Reference & Service Catalog

The OpsFlow REST API is fully compliant with the OpenAPI 3.0 specification and accessible via the interactive Swagger UI at http://localhost:5001/api-docs.

Method Endpoint Description
GET /api/v1/health System telemetry, database latency probe, and memory usage statistics.
POST /api/v1/auth/login Authenticate user credentials and obtain session JWT token.
POST /api/v1/auth/totp/verify Validate 6-digit TOTP token during zero-trust two-factor authentication.
GET /api/v1/tasks Query paginated tasks with department, priority, and status filters.
POST /api/v1/tasks Create a new engineering task and dispatch automation triggers.
GET /api/v1/incidents Fetch active incidents, severity classifications, and SLA status.
POST /api/v1/incidents/:id/war-room Broadcast message or status marker to the active Incident War Room.
GET /api/v1/automations List active event-driven automation rules and trigger histories.
POST /api/v1/copilot/chat Execute local SRE AI Copilot reasoning and query generation.
GET /api/v1/audit-logs Fetch immutable, tenant-isolated security and compliance audit logs.
Interactive Developer Portal: For complete request/response schemas, live parameter testing, and code generation snippets in cURL, Python, and JavaScript, visit the Developer Portal at http://localhost:5001.
